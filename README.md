# Sistema de Inventario con Python y PostgreSQL

Sistema de gestión de inventario desarrollado en Python, utilizando PostgreSQL como base de datos relacional.

## Tecnologías utilizadas
- Python
- PostgreSQL
- Psycopg
- Python-dotenv
- Git y GitHub

## Funcionalidades
- Registrar nuevos productos.
- Consultar productos existentes.
- Buscar productos.
- Actualizar información de productos.
- Eliminar productos con confirmación.
- Consultar estadísticas del inventario.
- Relacionar productos con categorías.

## Base de datos
El sistema utiliza PostgreSQL para almacenar información de productos, precios, existencias y categorías.

Las credenciales de conexión se configuran mediante variables de entorno para evitar incluir contraseñas en el código fuente.

## Objetivo
Proyecto práctico desarrollado para fortalecer habilidades en Python, SQL, bases de datos relacionales y control de versiones con Git.
